# The_fainal_work
Финальная работа по Selenium and Python
# Проект по автоматизации тестирования: Selenium WebDriver + Python + pytest

## 📌 О проекте

Данный репозиторий представляет собой **выпускную квалификационную работу** по курсу автоматизации тестирования. В процессе выполнения были изучены и закреплены на практике ключевые навыки написания автотестов для веб-приложений с использованием современных инструментов.

Проект демонстрирует:
- Полный цикл разработки автотестов от простых скриптов до модульных тестов
- Применение паттернов и best practices в автоматизации
- Работу с различными видами ожиданий и сложными элементами интерфейса
- Настройку тестового окружения и конфигурацию тестового фреймворка

## 📂 Структура проекта

Репозиторий организован как последовательное изучение тем с закреплением на практических заданиях:

### 1. Основы Selenium (lesson1_*.py)
- Поиск элементов по CSS, XPath
- Методы find_element / find_elements
- Работа с атрибутами элементов

### 2. Взаимодействие с элементами (lesson2_*.py)
- Клики по чекбоксам и радиокнопкам
- Метод `get_attribute()`
- Использование `execute_script` для скролла и работы с JavaScript
- Загрузка файлов на страницу
- Обработка alert и переход между вкладками браузера

### 3. Ожидания в тестах (lesson2_4_*.py)
- Неявные ожидания (`implicitly_wait`)
- Явные ожидания (`WebDriverWait` + `expected_conditions`)
- `time.sleep()` и когда его избегать

### 4. Тестовый фреймворк pytest (test_*.py)
- **Фикстуры** с различной областью видимости (`scope="function"`, `scope="class"`)
- Возврат значений из фикстур и их использование
- Автоиспользование фикстур (`autouse=True`)
- **Параметризация** тестов
- **Маркировка** тестов: `@pytest.mark.smoke`, `@pytest.mark.regression`
- Конфигурация в `pytest.ini` для регистрации пользовательских меток
- **XFail**: пометка ожидаемо падающих тестов с указанием причины
- **Перезапуск упавших тестов** с помощью плагина `pytest-rerunfailures`

### 5. Продвинутая настройка (conftest.py, test_parser.py)
- Централизованная конфигурация фикстур в `conftest.py`
- Передача параметров из командной строки в тесты
- Поддержка разных языков интерфейса через параметры запуска

### 6. Стили написания тестов
- **Unittest** (`test_abs_project.py`, `test_of_unittest.py`)
- **pytest** (основной подход)
- Сравнение и выбор оптимального подхода
